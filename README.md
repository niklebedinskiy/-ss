# Шаховий тренер (Android)

Kotlin + Jetpack Compose. Тренер розмовляє українською.

## Як зібрати
1. Встановіть Android Studio (Koala або новіша).
2. File → Open → оберіть цю папку, дочекайтесь Gradle Sync.
3. Підключіть телефон (або емулятор) і натисніть Run ▶.
   APK: Build → Build APK(s).

## Рівні
1 Початківець (~400), 2 Новачок (~800), 3 Любитель (~1200), 4 Експерт (~1700), 5 Майстер (~2000).

## Структура
- chess/Chess.kt — правила, легальні ходи (перевірено perft)
- chess/Engine.kt — рушій (alpha-beta, quiescence) і рівні складності
- Coach.kt — репліки тренера українською
- GameViewModel.kt — стан гри
- ui/ — дошка, екрани, малюнки фігур і тренера
